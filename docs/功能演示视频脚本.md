// 生成Token
public String generateToken(String username, Long userId) {
    Date expireDate = new Date(System.currentTimeMillis() + expiration * 1000);
    return Jwts.builder()
            .setSubject(username)
            .claim("userId", userId)
            .setIssuedAt(new Date())
            .setExpiration(expireDate)
            .signWith(SignatureAlgorithm.HS512, secret)
            .compact();
}
```

**讲解要点**：
- JWT由Header、Payload、Signature三部分组成
- 使用HS512算法签名
- Token有效期24小时
- 存储在Redis中便于管理

@Transactional
public void createReservation(ReservationRequest request) {
    // 1. 生成预订单号
    String reservationNo = generateReservationNo();
    
    // 2. 计算入住天数和总价
    long nights = ChronoUnit.DAYS.between(
        request.getCheckInDate(), 
        request.getCheckOutDate()
    );
    BigDecimal totalPrice = roomType.getPrice()
        .multiply(BigDecimal.valueOf(nights));
    
    // 3. 保存预订记录
    reservation.setReservationNo(reservationNo);
    reservation.setNights((int) nights);
    reservation.setTotalPrice(totalPrice);
    reservationMapper.insert(reservation);
    
    // 4. 更新房间状态为已预订
    if (request.getRoomId() != null) {
        roomMapper.updateStatus(request.getRoomId(), 1);
    }
}
```

**讲解要点**：
- 使用@Transactional保证事务一致性
- 自动计算入住天数和总价
- 预订时可选择是否分配具体房间

@Transactional
public void checkOut(CheckOutRequest request) {
    CheckIn checkIn = checkInMapper.selectById(request.getCheckInId());
    
    // 1. 计算应付金额
    BigDecimal totalAmount = checkIn.getTotalPrice()
        .add(checkIn.getExtraCharges())
        .subtract(checkIn.getDiscount());
    
    // 2. 计算退还押金
    BigDecimal refundDeposit = checkIn.getDeposit()
        .subtract(totalAmount.subtract(checkIn.getPaidAmount()));
    
    // 3. 更新入住状态
    checkIn.setStatus(1); // 已退房
    checkIn.setCheckOutTime(LocalDateTime.now());
    checkInMapper.updateById(checkIn);
    
    // 4. 更新房间状态为清洁中
    roomMapper.updateStatus(checkIn.getRoomId(), 3);
    
    // 5. 生成退款账单
    if (refundDeposit.compareTo(BigDecimal.ZERO) > 0) {
        createRefundBill(checkIn, refundDeposit);
    }
    
    // 6. 更新客户消费统计
    customerMapper.updateConsumption(
        checkIn.getCustomerId(), 
        totalAmount
    );
}
```

**讲解要点**：
- 事务保证数据一致性
- 自动计算退还押金
- 更新房间状态和客户消费记录

@Component
public class DailyReportJob implements Job {
    
    @Override
    public void execute(JobExecutionContext context) {
        LocalDate yesterday = LocalDate.now().minusDays(1);
        
        // 统计营收
        BigDecimal roomRevenue = billMapper.sumByTypeAndDate(0, yesterday);
        BigDecimal consumeRevenue = billMapper.sumByTypeAndDate(1, yesterday);
        
        // 统计入住率
        int totalRooms = roomMapper.countAll();
        int occupiedRooms = checkInMapper.countOccupiedByDate(yesterday);
        BigDecimal occupancyRate = BigDecimal.valueOf(occupiedRooms)
            .divide(BigDecimal.valueOf(totalRooms), 4, RoundingMode.HALF_UP)
            .multiply(BigDecimal.valueOf(100));
        
        // 保存日报表
        DailyReport report = new DailyReport();
        report.setReportDate(yesterday);
        report.setRoomRevenue(roomRevenue);
        report.setOccupancyRate(occupancyRate);
        dailyReportMapper.insert(report);
    }
}
```

**讲解要点**：
- 使用Quartz定时任务框架
- 每天凌晨1点自动生成前一天报表
- 统计营收、入住率等关键指标

```java
@Configuration
@EnableWebSecurity
@EnableGlobalMethodSecurity(prePostEnabled = true)
public class SecurityConfig extends WebSecurityConfigurerAdapter {
    
    @Override
    protected void configure(HttpSecurity http) throws Exception {
        http.csrf().disable()
            .sessionManagement()
                .sessionCreationPolicy(SessionCreationPolicy.STATELESS)
            .and()
            .authorizeRequests()
                .antMatchers("/api/auth/**").permitAll()
                .antMatchers("/swagger-ui/**").permitAll()
                .anyRequest().authenticated()
            .and()
            .addFilterBefore(jwtAuthenticationFilter, 
                UsernamePasswordAuthenticationFilter.class);
    }
}
```

**讲解要点**：
- 基于RBAC模型的权限控制
- JWT无状态认证
- 支持方法级别的权限注解
