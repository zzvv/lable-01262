## 1. 数据库概述

### 1.1 设计原则

1. **规范化设计**：遵循第三范式，减少数据冗余
2. **逻辑删除**：使用 deleted 字段标记删除，保留历史数据
3. **审计字段**：所有表包含 create_time 和 update_time
4. **状态机设计**：使用 status 字段管理业务状态流转
5. **索引优化**：为高频查询字段建立索引

### 1.2 命名规范

| 类型 | 规范 | 示例 |
|------|------|------|
| 表名 | 小写下划线 | sys_user, room_type |
| 字段名 | 小写下划线 | create_time, room_number |
| 主键 | id | id BIGINT |
| 外键 | 表名_id | customer_id, room_id |
| 索引 | idx_字段名 | idx_status |
| 唯一索引 | uk_字段名 | uk_username |
