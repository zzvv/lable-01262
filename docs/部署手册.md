## 2. 开发环境部署

### 2.1 安装JDK 8

**macOS (Homebrew)**
```bash
brew install openjdk@8
echo 'export PATH="/opt/homebrew/opt/openjdk@8/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc
java -version
```

**Ubuntu/Debian**
```bash
sudo apt update
sudo apt install openjdk-8-jdk
java -version
```

**Windows**
1. 下载 JDK 8: https://adoptium.net/
2. 安装并配置环境变量 JAVA_HOME
3. 添加 %JAVA_HOME%\bin 到 PATH

### 2.2 安装Node.js 16+

**macOS (Homebrew)**
```bash
brew install node@18
node -v
npm -v
```

**Ubuntu/Debian**
```bash
curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
sudo apt install -y nodejs
node -v
```

**Windows**
1. 下载 Node.js: https://nodejs.org/
2. 安装并验证: `node -v`

### 2.3 安装MySQL 8.0

**macOS (Homebrew)**
```bash
brew install mysql@8.0
brew services start mysql@8.0
mysql_secure_installation
```

**Ubuntu/Debian**
```bash
sudo apt install mysql-server
sudo systemctl start mysql
sudo mysql_secure_installation
```

**Docker方式**
```bash
docker run -d \
  --name mysql \
  -p 3306:3306 \
  -e MYSQL_ROOT_PASSWORD=root123 \
  -e MYSQL_DATABASE=hotel_management \
  mysql:8.0
```

### 2.4 安装Redis 7.x

**macOS (Homebrew)**
```bash
brew install redis
brew services start redis
redis-cli ping
```

**Ubuntu/Debian**
```bash
sudo apt install redis-server
sudo systemctl start redis
redis-cli ping
```

**Docker方式**
```bash
docker run -d \
  --name redis \
  -p 6379:6379 \
  redis:7-alpine
```

## 3. 项目配置

### 3.1 克隆项目

```bash
git clone <repository-url>
cd hotel-management
```

### 3.2 数据库初始化

```bash
# 登录MySQL
mysql -u root -p

# 执行初始化脚本
source database/hotel_management_full.sql
```

或使用Navicat等工具直接导入 `database/hotel_management_full.sql`

### 3.3 后端配置

编辑 `backend/src/main/resources/application-dev.yml`:

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/hotel_management?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai
    username: root
    password: your_password  # 修改为你的密码
    
  redis:
    host: localhost
    port: 6379
    password:  # 如有密码则填写
```

### 3.4 前端配置

编辑 `frontend/vite.config.js` 中的代理配置（如需修改后端地址）:

```javascript
server: {
  proxy: {
    '/api': {
      target: 'http://localhost:8080',  // 后端地址
      changeOrigin: true
    }
  }
}
```

### 4.1 启动后端


## 5. Docker部署（推荐）

### 5.1 安装Docker

**macOS**
```bash
brew install --cask docker
# 启动Docker Desktop
```

**Ubuntu**
```bash
curl -fsSL https://get.docker.com | sh
sudo usermod -aG docker $USER
sudo systemctl start docker
```

### 5.2 一键部署

```bash
# 在项目根目录执行
docker-compose up -d

# 查看服务状态
docker-compose ps

# 查看日志
docker-compose logs -f
```

### 5.3 docker-compose.yml 说明

```yaml
version: '3.8'

services:
  # MySQL数据库
  mysql:
    image: mysql:8.0
    container_name: hotel-mysql
    environment:
      MYSQL_ROOT_PASSWORD: root123
      MYSQL_DATABASE: hotel_management
    ports:
      - "3306:3306"
    volumes:
      - mysql_data:/var/lib/mysql
      - ./database:/docker-entrypoint-initdb.d  # 自动初始化
    command: --character-set-server=utf8mb4 --collation-server=utf8mb4_unicode_ci

  # Redis缓存
  redis:
    image: redis:7-alpine
    container_name: hotel-redis
    ports:
      - "6379:6379"
    volumes:
      - redis_data:/data

  # 后端服务
  backend:
    build: ./backend
    container_name: hotel-backend
    ports:
      - "8080:8080"
    environment:
      SPRING_PROFILES_ACTIVE: docker
    depends_on:
      - mysql
      - redis

  # 前端服务
  frontend:
    build: ./frontend
    container_name: hotel-frontend
    ports:
      - "80:80"
    depends_on:
      - backend

volumes:
  mysql_data:
  redis_data:
```

### 5.4 服务访问地址

| 服务 | 地址 |
|------|------|
| 前端 | http://localhost |
| 后端API | http://localhost:8080 |
| Swagger | http://localhost:8080/swagger-ui/index.html |
| MySQL | localhost:3306 |
| Redis | localhost:6379 |

### 5.5 常用Docker命令

```bash
# 停止所有服务
docker-compose down

# 重新构建并启动
docker-compose up -d --build

# 查看某个服务日志
docker-compose logs -f backend

# 进入容器
docker exec -it hotel-backend sh

# 清理所有数据（慎用）
docker-compose down -v
```

## 6. 生产环境部署

### 6.1 服务器准备

```bash
# 创建应用目录
sudo mkdir -p /opt/hotel-management
sudo chown -R $USER:$USER /opt/hotel-management

# 安装必要软件
sudo apt update
sudo apt install -y openjdk-8-jdk nginx
```

### 6.2 后端部署

```bash
# 上传jar包
scp target/hotel-management-1.0.0.jar user@server:/opt/hotel-management/

# 创建启动脚本
cat > /opt/hotel-management/start.sh << 'EOF'
#!/bin/bash
APP_NAME=hotel-management-1.0.0.jar
APP_HOME=/opt/hotel-management
LOG_FILE=$APP_HOME/app.log

cd $APP_HOME
nohup java -Xms512m -Xmx1024m \
  -jar $APP_NAME \
  --spring.profiles.active=prod \
  > $LOG_FILE 2>&1 &

echo "Application started, PID: $!"
EOF

chmod +x /opt/hotel-management/start.sh

# 启动应用
/opt/hotel-management/start.sh
```

### 6.3 前端部署

```bash
# 本地构建
cd frontend
npm run build

# 上传dist目录
scp -r dist/* user@server:/var/www/hotel/
```

### 6.4 Nginx配置

```nginx
# /etc/nginx/sites-available/hotel
server {
    listen 80;
    server_name your-domain.com;

    # 前端静态文件
    location / {
        root /var/www/hotel;
        index index.html;
        try_files $uri $uri/ /index.html;
    }

    # 后端API代理
    location /api {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_connect_timeout 60s;
        proxy_read_timeout 60s;
    }

    # Gzip压缩
    gzip on;
    gzip_types text/plain text/css application/json application/javascript;
}
```

```bash
# 启用配置
sudo ln -s /etc/nginx/sites-available/hotel /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx
```

### 6.5 Systemd服务（可选）

```bash
# 创建服务文件
sudo cat > /etc/systemd/system/hotel-backend.service << 'EOF'
[Unit]
Description=Hotel Management Backend
After=network.target mysql.service redis.service

[Service]
Type=simple
User=www-data
WorkingDirectory=/opt/hotel-management
ExecStart=/usr/bin/java -Xms512m -Xmx1024m -jar hotel-management-1.0.0.jar --spring.profiles.active=prod
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
EOF

# 启用服务
sudo systemctl daemon-reload
sudo systemctl enable hotel-backend
sudo systemctl start hotel-backend
sudo systemctl status hotel-backend
```

## 7. 常见问题

### 7.1 端口被占用

```bash
# 查看端口占用
lsof -i :8080
netstat -tlnp | grep 8080

# 杀死进程
kill -9 <PID>
```

### 7.2 MySQL连接失败

```bash
# 检查MySQL状态
systemctl status mysql

# 检查连接
mysql -u root -p -h localhost

# 授权远程访问
GRANT ALL PRIVILEGES ON hotel_management.* TO 'root'@'%' IDENTIFIED BY 'password';
FLUSH PRIVILEGES;
```

### 7.3 Redis连接失败

```bash
# 检查Redis状态
systemctl status redis
redis-cli ping

# 检查配置
cat /etc/redis/redis.conf | grep bind
```

### 7.4 前端构建失败

```bash
# 清理缓存
rm -rf node_modules package-lock.json
npm cache clean --force
npm install
```

### 7.5 内存不足

```bash
# 调整JVM参数
java -Xms256m -Xmx512m -jar hotel-management-1.0.0.jar

# 或修改Docker配置
deploy:
  resources:
    limits:
      memory: 1G
```

## 9. 版本升级

### 9.1 后端升级

```bash
# 停止服务
systemctl stop hotel-backend

# 备份旧版本
mv hotel-management-1.0.0.jar hotel-management-1.0.0.jar.bak

# 上传新版本
scp hotel-management-1.1.0.jar user@server:/opt/hotel-management/

# 启动服务
systemctl start hotel-backend
```

### 9.2 数据库升级

```bash
# 备份数据
mysqldump -u root -p hotel_management > backup_before_upgrade.sql

# 执行升级脚本
mysql -u root -p hotel_management < upgrade_v1.1.0.sql
```

### 9.3 回滚

```bash
# 停止服务
systemctl stop hotel-backend

# 恢复旧版本
mv hotel-management-1.0.0.jar.bak hotel-management-1.0.0.jar

# 恢复数据库
mysql -u root -p hotel_management < backup_before_upgrade.sql

# 启动服务
systemctl start hotel-backend
```
