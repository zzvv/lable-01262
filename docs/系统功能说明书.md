# 酒店管理系统 - 功能说明书

## 1. 系统概述

### 1.1 系统简介
酒店管理系统是一套基于 SpringBoot + Vue3 的前后端分离系统，提供完整的酒店日常运营管理功能，包括房间管理、预订管理、入住管理、客户管理、财务管理和系统管理等模块。

### 1.2 技术架构

| 层级 | 技术选型 |
|------|----------|
| 前端 | Vue 3 + Element Plus + Vite + ECharts |
| 后端 | SpringBoot 2.7 + MyBatis Plus + Spring Security |
| 数据库 | MySQL 8.0 + Redis 7.x |
| 定时任务 | Quartz |
| 部署 | Docker + Nginx |

## 2. 功能模块说明

### 2.1 首页仪表盘

**功能描述**：展示酒店运营核心数据概览

**主要功能**：
- 今日营收统计
- 入住率展示
- 待处理预订数量
- 当前入住房间数
- 近7天营收趋势图
- 房型入住分布图
- 今日入住/退房列表

**数据来源**：
- 实时查询 check_in、bill、reservation 表
- 聚合计算入住率、营收等指标

---

### 2.2 房间管理模块

#### 2.2.1 房型管理
**功能描述**：管理酒店房间类型

**主要功能**：
- 房型列表查询（支持分页、搜索）
- 新增房型（名称、价格、床型、面积、最大入住人数）
- 编辑房型信息
- 删除房型（逻辑删除）
- 房型上架/下架

**数据表**：room_type

#### 2.2.2 房间列表
**功能描述**：管理具体房间信息

**主要功能**：
- 房间列表查询（支持按房型、状态、楼层筛选）
- 新增房间（房间号、房型、楼层）
- 编辑房间信息
- 删除房间
- 修改房间状态（空闲/清洁中/维修中）

**数据表**：room

#### 2.2.3 房态总览
**功能描述**：可视化展示所有房间当前状态

**主要功能**：
- 按楼层分组展示房间
- 颜色区分房间状态（空闲-绿色、已预订-黄色、入住中-红色、清洁中-蓝色、维修中-灰色）
- 点击房间查看详情
- 快速操作（办理入住、查看入住信息）

---

### 2.3 预订管理模块

#### 2.3.1 预订列表
**功能描述**：管理所有预订记录

**主要功能**：
- 预订列表查询（支持按状态、日期、客户筛选）
- 查看预订详情
- 确认预订
- 取消预订（需填写取消原因）
- 预订转入住

**预订状态流转**：
```
待确认(0) → 已确认(1) → 已入住(2) → 已完成(3)
    ↓           ↓
已取消(4)   已取消(4)
```

**数据表**：reservation

#### 2.3.2 新建预订
**功能描述**：创建新的预订记录

**主要功能**：
- 选择/新建客户
- 选择房型和房间数量
- 选择入住日期和离店日期
- 自动计算预订总价
- 设置押金金额
- 选择预订来源（前台/网站/APP/第三方）

**业务规则**：
- 自动生成预订单号（RSV + 日期 + 序号）
- 检查房间可用性
- 计算入住天数

---

### 2.4 入住管理模块

#### 2.4.1 入住列表
**功能描述**：管理所有入住记录

**主要功能**：
- 入住列表查询（支持按状态、日期、房间筛选）
- 查看入住详情
- 办理续住
- 办理退房结算

**入住状态**：
| 状态 | 说明 |
|------|------|
| 入住中(0) | 客户正在住店 |
| 已退房(1) | 已完成退房结算 |
| 续住中(2) | 办理了续住 |

**数据表**：check_in, check_in_guest

#### 2.4.2 办理入住
**功能描述**：为客户办理入住手续

**主要功能**：
- 从预订转入住 / 散客直接入住
- 选择/新建客户
- 选择房间
- 登记同住人信息
- 收取押金
- 自动生成房费账单

**业务流程**：
1. 选择客户（支持身份证/手机号搜索）
2. 选择可用房间
3. 填写入住信息（预计离店日期、押金）
4. 登记同住人（姓名、身份证）
5. 确认入住
6. 更新房间状态为"入住中"
7. 生成押金账单

#### 2.4.3 退房结算
**功能描述**：办理客户退房和费用结算

**主要功能**：
- 查看房费明细
- 查看消费明细
- 添加额外消费
- 计算应付金额
- 选择支付方式
- 退还押金
- 打印结算单

**结算公式**：
```
实付金额 = 房费总计 + 额外消费 - 折扣 - 已付金额
退还押金 = 押金 - 未付金额（如有）
```

### 2.5 客户管理模块

**功能描述**：管理酒店客户信息

**主要功能**：
- 客户列表查询（支持姓名、手机号、身份证搜索）
- 新增客户
- 编辑客户信息
- 查看客户消费历史
- 会员等级管理

**会员等级**：
| 等级 | 名称 | 说明 |
|------|------|------|
| 0 | 普通 | 默认等级 |
| 1 | 银卡 | 累计消费满3000 |
| 2 | 金卡 | 累计消费满10000 |
| 3 | 钻石 | 累计消费满30000 |

**数据表**：customer

---

### 2.6 财务管理模块

#### 2.6.1 账单管理
**功能描述**：管理所有财务账单

**主要功能**：
- 账单列表查询（支持按类型、状态、日期筛选）
- 查看账单详情
- 账单支付
- 账单退款
- 导出账单

**账单类型**：
| 类型 | 说明 |
|------|------|
| 房费(0) | 住宿费用 |
| 消费(1) | 客房消费（餐饮、洗衣等） |
| 押金(2) | 入住押金 |
| 退款(3) | 退款记录 |

**支付方式**：现金、微信、支付宝、银行卡、挂账

**数据表**：bill

#### 2.6.2 统计报表
**功能描述**：展示营收统计和经营分析

**主要功能**：
- 日报表查询
- 月报表查询
- 营收趋势图
- 房型收入分析
- 入住率统计
- 报表导出

**报表数据**：
- 总营收、房费收入、消费收入
- 入住数、退房数、预订数
- 新增客户数
- 入住率

**数据表**：daily_report, monthly_report

**主要功能**：

**菜单类型**：
| 类型 | 说明 |

## 5. 部署说明

### 5.1 环境要求
- JDK 8+
- Node.js 16+
- MySQL 8.0+
- Redis 7.x
- Docker (可选)

### 5.2 Docker部署
```bash
# 启动所有服务
docker-compose up -d

# 查看服务状态
docker-compose ps
```
